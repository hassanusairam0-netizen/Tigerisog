# LONGXING 龍行 — Dragon Stride

An interactive 3D website for a handmade yellow and red sneaker, made by Tiger and Massi.

- Scroll-driven 3D shoe journey (Three.js + GSAP ScrollTrigger)
- Four lifestyle environments: Sport, Everyday, Studio, Night out
- Working 360° viewer with drag, zoom, preset views and detail markers
- Chinese-inspired visual identity: cloud scrolls, ink brush strokes, seal mark

The 3D shoe is built in code from the four reference photos in `img/`. It is not a 3D scan, so proportions and panel outlines are close approximations.

## Run it

Open `index.html` through any static web server, for example:

```
npx serve .
```

or enable GitHub Pages for this repository (Settings → Pages → deploy from the `main` branch).
